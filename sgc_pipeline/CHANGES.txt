CHANGES.txt — how these scripts differ from the originals you first uploaded
============================================================================
Read this when comparing the pipeline against earlier versions. Only
ONE change alters pipeline numbers (verbose_summary.sh, flagged ***); the rest
are new scripts or added capability with the same core behaviour.

*** BEHAVIOUR CHANGE THAT AFFECTS PIPELINE OUTPUT ***
-----------------------------------------------------
verbose_summary.sh
  MHC representative selection changed:
    OLD  keep the MHC clump with the MOST GW-sig variants (tie -> strongest p)
    NEW  keep the MHC clump with the MOST SIGNIFICANT index SNP (lowest index
         p; tie -> richer clump)
  Effect: the single variant shown as the MHC representative on the
  Clump_index_variants tab may change (now the strongest-p MHC lead, matching
  the old index_snps.sh behaviour you asked to restore). Locus COUNTS are
  unaffected (MHC is one locus either way); only which variant id represents
  it changes. n_gwsig_in_clump reported is that chosen clump's own count.

  NOTE: the Python locus-builders (cross_disease_verbose.py,
  heatmap_trait_locus.py, highlights_top_loci.py, count_unique_clumps.py) still
  collapse the MHC by their own most-common-index/lowest-p rule, so the MHC
  representative VARIANT can differ between those tabs and Clump_index_variants.
  Counts remain correct everywhere. Ask if you want them all aligned.
